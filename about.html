Count!

This is a simple tool I made to practice counting territory in go.

For each position, count which side is winning, assuming no komi and no prisoners. All positions have the same number of black and white stones, and there are no sekis, so area scoring and territory scoring will give the same result.

The positions are manually generated, and the game supports 9x9, 13x13, and 19x19 board sizes. They are presented at random orientations. To avoid tempting you to memorize specific positions, for many of them I've included a very similar position where the result is the opposite.

When you load the page, you are prompted to choose:

  • Seconds per board: Time limit for each position. Leave empty for no timer.
  • Board size: Choose 9, 13, 19, or "random" for a mix.
  • Mode: Choose "normal" (who is winning) or "hardcore" (who is winning AND by how much).

The game continues until you run out of time or give an incorrect answer. Set your own personal goal (for instance "20 boards in 20 seconds each") and work towards it by gradually reducing the timer!

If you're playing from a computer, you might prefer using the left and right arrow keys instead of the black and white buttons on screen (you can also use enter to restart).

If you have any feedback, please let me know in this forum thread!
